# 汪汪队立大功 · Wangwang Team Saves the Day

一个**本地运行的 CTF 解题助手**：把 DeepSeek 接进一个可视化界面，给它题库、给它能动手的沙箱、
再给它一套会越用越好的「技能库」，让它像队友一样陪你打比赛。

> 定位：**机器搬砖，你拍板**。它负责读题、拆文件、写脚本、跑命令、整理结论；
> 是否提交、提交什么，永远由你决定。

---

## 它解决什么问题

打 CTF 最耗时间的不是"想不到"，而是这几件事：

- 附件一堆，不知道先看哪个
- 脚本写了一版又一版，每版都要重新想
- 走过的死路没人记，下次还走
- 时间被杂活吃掉，真正该思考的地方反而没时间

这个工具把上面这些交给模型，同时用「技能库 + 复盘回流」让**每一场比赛都在给它积累经验**。

---

## 核心特性

### 1. 可视化工作台

- 领题 / 看题面 / 下载附件 / 看进度 / 提交 flag，全在一个页面
- 实时显示模型的每一步：它想了什么、跑了什么命令、看到了什么输出
- 提交次数常驻显示，剩得少会变色提醒

### 2. 六类题型的技能库

`skills/` 下是**按题型组织的作战手册**，每次解题时自动注入对应章节：

| 文件 | 内容 |
|---|---|
| `general.md` | **通用思考方式**：问题空间 → 核心等式 → 可逆性 → 成本预估 → 探针定位 |
| `reverse.md` | 静态流程 / 远程调试 / 伪 proc 绕反调试 / 逐字节对齐 / Android ARM64 |
| `pwn.md` | 堆利用套路 / tcache 三部曲 / `__free_hook` 之后的三道坎 / 爆破模板 |
| `web.md` | 结构优先 / 三种探针 / PHP disable_functions 绕过 / 无参命令执行 |
| `crypto.md` | RSA 弱点清单 / 矩阵相似变换求特征向量 |
| `misc.md` | 分类流程 / 一次性探针 / 流量分析固定流程 |

这些文件是**纯 Markdown，你可以随时改**。加了什么经验，下次解题立刻生效。

### 3. 工具箱（拿来就能用）

`toolbox/` 里是可以直接调用的文件，不是文档里的代码块：

| 文件 | 用途 |
|---|---|
| `matrix_eigen_flag.py` | 矩阵型 crypto 题求解器（特征向量 → flag），纯标准库 |
| `launcher_fakeproc.c` | 伪造 `/proc` 骗过 ptrace 检测 |
| `gdb_dump.gdb` / `gdb_call.gdb` | gdb 批量断点 dump / 直接调用内部函数 |
| `brute_template.c` | 多线程哈希原像爆破 |
| `verify_elf.py` | 一次看清 ELF（类型 / PIE / 符号 / 高信号字符串） |
| `patch_bytes.py` | 安全地改二进制（先断言原字节） |
| `vmops.py` | 一键操作 Kali 虚拟机（找 IP / 跑命令 / 传文件 / 跑 ELF） |

### 4. 几个防呆设计

这些是踩坑之后加上的，每一条都对应一次真实的浪费：

- **自动源码回溯**：工具输出很短（像 `die("O.o")` 这种）时，自动去题目源码里
  找到它的出处，把上下文贴回给模型——避免它以为"这个 payload 不行，换一个"
- **打转检测**：同一个短输出出现第 3 次，强制提醒「别换输入，先解释这个输出」
- **方向检查点**：第 15 / 28 步强制回顾「我现在确信什么？还有什么没排除？」
- **成本估算**：`run_cmd` 必须给超时，逼模型在跑之前想"这一步要多久"
- **进程树清理**：超时用 `taskkill /T` 杀整棵树，避免 `pip install` 这类把任务永久挂死
- **答案自检**：`finish` 必须填「是否本地验证过」+「证据」，没验证的答案在界面上标成橙色
- **自动复盘**：每次任务结束自动生成 `writeups/*.md`，记录手法、死路、结论

## 快速开始

```bash
# 1. 需要 Python 3.9+
python --version

# 2. 双击或执行
启动.bat
```

启动后浏览器打开 `http://127.0.0.1:8791/`，在右上角 **⚙ 设置** 里填：

| 配置项 | 说明 |
|---|---|
| `ai_key` | DeepSeek API Key（必填） |
| `ai_base` | 默认 `https://api.deepseek.com/v1` |
| `ai_model` | 默认 `deepseek-chat`，换更强的模型效果更好 |
| NSSCTF token | 在设置里填，用于领题/提交（只玩本地题目可以不填） |

**不接平台也能用**：左边有「本地解题」区，自己丢附件进去让它解。

## 目录结构

```
.
├─ app/
│  ├─ server.py      本地 HTTP 服务（127.0.0.1）
│  ├─ ai.py          模型层：agent 循环 + 工具定义 + 提示词组装
│  ├─ core.py        平台接口 + 题库管理
│  ├─ reflux.py      复盘回流：日志 → writeup / 技能条目
│  └─ ui.html        单页界面
├─ skills/           按题型组织的作战手册（Markdown，可随时改）
├─ toolbox/          可直接调用的工具脚本
├─ tools/            conn.py / winops.py / vmops.py
├─ data/             本地配置与状态（不提交到仓库）
├─ logs/             每次解题的完整日志
└─ writeups/         自动生成的复盘文档
```

---

## 它是怎么"变聪明"的

```
解题 → 产生日志 → 自动生成 writeup → 人工确认后回流进 skills/
     ↑                                          │
     └────────────── 下次解题自动注入 ────────────┘
```

单次比赛看是"帮忙跑腿"，跑上十场之后，`skills/` 会积累成一套**针对你自己的打法手册**。
